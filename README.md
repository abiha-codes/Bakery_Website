
# 🧁 Bakery Website

A beautiful and responsive bakery website built using HTML, CSS, and JavaScript. Explore delicious cakes, cheesecakes, new arrivals, customer reviews, and more!

## 🌐 Live Demo

🔗 [View Live Website](https://bakery-website-silk-rho.vercel.app/)

## 📸 Project Screenshot

![Bakery Website Screenshot](./Bakery%20Website/Picture.png)

## ✨ Features

- 🧁 Attractive bakery homepage
- 🎂 Cakes and cheesecakes sections
- 🍪 New arrivals showcase
- ⭐ Customer reviews section
- 📍 Contact section with an embedded map
- 🔍 Interactive search bar
- 🛒 Shopping cart panel
- 📱 Responsive design for different screen sizes
- 🎨 Beautiful colors and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
